# 猜数字小游戏 (Guess the Number)

一个用 Python 写的命令行小游戏：电脑随机想一个 **1 到 100** 之间的整数，
你来猜。每猜一次，程序会告诉你 **"大了"** 还是 **"小了"**，
直到猜中为止，最后告诉你一共猜了多少次。

整个游戏只用 **一个文件** 实现，代码只有 80 行左右，加了详细中文注释，
适合作为 Python 入门的第一个小项目。

## 游戏玩法

1. 程序在 1~100 里随机挑一个数字，记在心里（不告诉你）。
2. 你输入一个猜测的数字，按回车。
3. 程序比较你的猜测和答案：
   - 猜的数 **比答案大** → 提示 `大了`
   - 猜的数 **比答案小** → 提示 `小了`
   - 猜的数 **正好等于答案** → 恭喜猜中，并告诉你猜了几次
4. 程序会一直重复第 2、3 步，直到你猜中。
5. 猜中之后会问你要不要 `再来一局`，输入 `y` 继续，按其他键退出。

**小技巧**：每次都猜"当前剩余范围的正中间"（比如先猜 50，再猜 25 或 75），
最多 7 次一定能猜中。这种思路叫**二分查找**。

## 如何运行

### 方法一：cmd 命令行运行（推荐）

1. 按键盘上的 **`Win` + `R`**，会弹出"运行"窗口。
2. 在输入框里输入 **`cmd`**，点确定或按回车，就打开了命令提示符。
3. 用 `cd` 命令切换到项目所在的文件夹（注意：换盘符要加 `/d`）：

   ```bat
   cd /d D:\play_do\first
   ```

4. 运行程序：

   ```bat
   python guess_number.py
   ```

5. 出现提示后，输入你猜的数字，按回车即可开始游戏。

> **小贴士**：在项目文件夹的地址栏里输入 `cmd` 再回车，
> 也能直接打开"已经定位到该文件夹"的命令提示符，省去第 3 步。

### 方法二：双击运行

直接双击 `guess_number.py` 文件即可。
缺点是：如果程序很快结束，窗口会一闪而过，看不到结果。
所以更推荐用上面的命令行方式。

## 代码逻辑讲解

代码在 `guess_number.py` 里，按下面的顺序阅读最清楚：

```text
main()  ->  play()  ->  read_guess()  ->  make_answer()
```

### 1. `make_answer()` —— 电脑出题

```python
def make_answer():
    return random.randint(LOW, HIGH)
```

`random.randint(1, 100)` 会随机返回一个 1 到 100 之间的整数（两端的数都能取到）。
这就是电脑"心里想的那个数字"。

### 2. `read_guess()` —— 读取并检查玩家的输入

```python
text = input("请输入你猜的数字（1-100）：").strip()
if not text.isdigit():
    print("输入无效，请输入一个 1-100 的整数。")
    return None
```

这一步做了**输入校验**，防止程序崩溃：

- `input()` 拿到的是**字符串**，不是数字，所以要转换；
- 如果玩家输入 `abc`、空行或者负数，`text.isdigit()` 会返回 `False`，
  函数就返回 `None` 表示"这次输入不算数"；
- 如果数字超出 1~100 的范围，也返回 `None`。

> 为什么要返回 `None` 而不是直接退出？这样上层可以简单地用
> `if guess is None: continue` 让它重新问一次。

### 3. `play()` —— 玩一整局

```python
answer = make_answer()
count = 0
while True:
    guess = read_guess()
    if guess is None:
        continue          # 输入不合法，不计次数，重新问
    count = count + 1     # 合法的一次猜测才计数
    if guess > answer:
        print("大了")
    elif guess < answer:
        print("小了")
    else:
        print(f"猜中了！答案就是 {answer}，你一共猜了 {count} 次。")
        break             # 猜中，跳出循环
```

核心就是一个 `while True` **无限循环**：

- 每次循环读一个猜测；
- 用 `if / elif / else` 三选一判断：大了、小了、猜中；
- 只有 `else`（也就是猜中）时才执行 `break` 跳出循环，本局结束；
- `count` 在每次**有效猜测**后加 1，这就是"猜了几次"的统计。

### 4. `main()` —— 程序入口，支持多局

```python
while True:
    play()
    again = input("再来一局吗？（输入 y 再来，其他任意键退出）：").strip().lower()
    if again != "y":
        print("游戏结束，再见！")
        break
```

外面再套一层循环：玩完一局问一次，输入 `y`（不分大小写，`.lower()` 就是干这个的）
就再玩一局，否则退出。

### 5. 最后两行

```python
if __name__ == "__main__":
    main()
```

这是 Python 的固定写法，意思是"**只有直接运行这个文件时才启动游戏**"。
如果以后别的文件把它 `import` 进去当工具用，游戏不会自动跑起来。

## 常见问题

**Q：cmd 里输入 `python` 提示"不是内部或外部命令"？**
A：说明 Python 没有添加到系统环境变量 PATH。解决办法：
重新安装 Python，在安装向导第一步勾选 **"Add Python to PATH"**。

**Q：输入 `cd D:\play_do\first` 之后还在 C 盘，没换过去？**
A：跨盘符切换要加 `/d` 参数，正确写法是 `cd /d D:\play_do\first`。

**Q：中文显示成乱码？**
A：cmd 默认编码可能是 GBK。可以在运行前先执行一次
`chcp 65001` 把编码切成 UTF-8，再运行程序。

**Q：程序跑起来一闪就没了？**
A：不要双击运行，改用命令行的方式启动，窗口就会停住。

**Q：最多可能猜到多少次？**
A：没有上限，理论上可以一直猜错。用二分法的话最多 7 次必定猜中
（因为 2⁷ = 128 > 100）。
